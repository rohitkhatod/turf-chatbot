# SEO Roadmap

## Technical SEO
- Implement optimized title/meta description for every core page.
- Add schema (`Organization`, `Product`, `BreadcrumbList`, `FAQPage`, `LocalBusiness` if applicable).
- Generate XML sitemap and submit to Google Search Console.
- Configure robots.txt.
- Ensure 301 redirects from old URLs.
- Improve Core Web Vitals (image optimization, caching, minified assets).

## On-Page SEO
- Keyword mapping by page intent.
- H1-H3 structure and semantic content blocks.
- Internal linking between products, categories, and blog posts.
- Alt text policy for all images.

## Content SEO
- Create cluster pages for high-value crop/agri topics.
- Add FAQ sections on product and category pages.
- Publish educational blog posts with seasonal themes.

## Off-Page/Authority
- Business profile consistency and citations.
- Partner/dealer backlink opportunities.
