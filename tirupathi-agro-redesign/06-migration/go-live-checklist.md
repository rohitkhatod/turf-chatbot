# Go-Live Checklist (WordPress + GoDaddy)

## Pre-Launch
- [ ] Full backup of existing website and database.
- [ ] Freeze content changes on old website.
- [ ] Validate all forms and email routing.
- [ ] Validate mobile responsiveness.
- [ ] Run page speed checks on top pages.
- [ ] Validate metadata and canonical tags.

## Launch
- [ ] Point production domain to new release.
- [ ] Clear cache and regenerate assets.
- [ ] Submit XML sitemap in Search Console.
- [ ] Verify analytics and conversion tracking.

## Post-Launch (First 14 Days)
- [ ] Monitor 404 and redirect errors.
- [ ] Monitor rankings and traffic trends.
- [ ] Fix high-priority UX/SEO defects.
